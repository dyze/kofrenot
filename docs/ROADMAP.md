# kofrenot: roadmap

Scope of each planned version. Implemented features move to [CHANGELOG.md](../CHANGELOG.md). The goal, principles, non-goals and open questions are in [GOAL.md](GOAL.md). The features are sorted by priority.

| Version | Status      | Theme                                                                          |
| ------- | ----------- | ------------------------------------------------------------------------------ |
| 0.1     | In progress | Application shell: main window, tray, settings, logging, updates, installer    |
| 0.2     | To define   | First notes, stored locally                                                    |

## 0.1
The skeleton taken from coursee, without its launcher features. See `[Unreleased]` in [CHANGELOG.md](../CHANGELOG.md).

## 0.2 (to define)
1. **Answer the open questions** needed for local notes (note format, local storage): [GOAL.md](GOAL.md#open-questions).
2. **Create, edit and delete notes**, stored locally.
3. **Organize notes** (folders and / or tags).
4. **Search the metadata** (titles, tags).
